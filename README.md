# AI CV ↔ Job Matcher

## Overview

AI CV ↔ Job Matcher is an NLP and LLM-powered application that analyses CVs against job descriptions using semantic similarity and AI-generated career recommendations.

The application allows users to:

* upload CVs as PDF or Word documents
* compare CVs against job descriptions
* calculate semantic similarity scores
* identify matched and missing skills
* receive AI-generated CV improvement suggestions
* generate stronger CV bullet points
* receive interview preparation advice
